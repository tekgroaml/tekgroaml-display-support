# Windows：画面和触摸先这样检查

[English](README.md) | **简体中文**

先做这些检查，不用一上来安装驱动或运行脚本。适用于Windows 10／11的常见操作，菜单名称可能略有不同。树莓派测试成功，不代表Windows也已验证通过。

## 碰一下线，屏幕就黑了或闪了

1. 先别动线，等约10～15秒。
2. 没恢复，就拔下HDMI和USB供电线重新插紧，电脑端也检查。
3. 换线试试，先只接一块屏，供电按商品要求连接。

如果轻碰就反复发生，优先换线，不要先改屏幕固件。

## 还是没画面、闪烁，或显示大小不对

1. 桌面右键→**显示设置**→**标识**，选中小屏幕。
2. 如果列表支持，选择与商品对应的分辨率，不照搬另一块屏的设置。
3. 双屏想分别显示时选**扩展这些显示器**；复制模式可能限制可选分辨率。
4. 进入**高级显示**，仍选这块屏，**仅在列表支持时**尝试60Hz。没有该选项或效果更差就恢复原设置。只有画面正常时才确认保留；Windows通常会短暂询问保留还是还原。
5. 四边完整但字太大时，可调整**缩放**。它只改变文字和软件大小，不能找回被屏幕硬件截掉的像素。

Windows完全检测不到屏幕时，先查供电和HDMI，再换已知正常的接口、线或电脑。能检测但仍黑屏时，提供照片和已选分辨率／刷新率联系支持。

## 有画面，但手指点了没反应

触摸款随附的USB供电／触摸线也传输触摸数据，必须接到**正在通过HDMI输出画面的同一台电脑**，不能只插充电头。用能传数据的USB线，纯充电线不行。非触摸款不会响应手指。

换电脑上的USB口，暂时绕过集线器，重新插接USB。打开**设备管理器→人体学输入设备**，查看是否有类似**符合HID标准的触摸屏**。若被禁用，可启用；若没有或带警告，先换数据线和接口，再联系支持，不先安装来路不明的驱动，也不禁用其他输入设备。

## 点小屏，却在另一块屏上操作

1. 核对每块屏的两根线是否接到正确主机，先逐块连接HDMI和USB测试。
2. 接回双屏，在显示设置中点**标识**确认编号。
3. 开始菜单搜索**校准笔和触控输入的屏幕**，在**Tablet PC设置**中点**设置（Setup）**；如有询问，选触摸输入。
4. 按提示触摸对应屏幕。提示出现在非触摸屏时，按Enter移到下一屏，完成后分别测试。

先做Setup，它用于指定触摸对应哪块屏，不是直接校准。不同Windows和控制器可用选项可能不同。如果没有此项，或仍控制同一屏，请提供接线照片及设备管理器截图。树莓派USB映射脚本不能配置Windows。

## 响应在本屏，但触点和手指对不上

先确认上面的分辨率、方向和触摸对应屏幕。如果以前做过Windows校准，可在Tablet PC设置中用**重置（Reset）**（如可用）后再试。普通矩形触摸屏可尝试**校准（Calibrate）**；圆屏可能看不到角落校准点，不要凭猜测点击隐藏位置。

6.2英寸切割屏先处理画面可见区域，再考虑校准；校准本身不能恢复被截掉的内容。见[切割屏产品FAQ](../../product-support/6.2inch-360x960-touch/README.zh-CN.md)。

## 6.2英寸屏幕左边内容不全

已测触摸样机只显示输入画面的一部分。文档里的树莓派应用补偿已验证过，但**尚未验证Windows整个桌面的修复方案**。不保证改分辨率、60Hz或做触摸校准就能恢复。请发完整屏幕照片及**高级显示**截图，由支持核对实物。

## 我需要运行脚本吗？

本支持文档里的`screen-config`、`screen-test`和Python切割屏演示，适用于**树莓派及文档指定的图形桌面环境**，不是Windows软件。Windows先按上面步骤处理，未恢复再联系支持。
