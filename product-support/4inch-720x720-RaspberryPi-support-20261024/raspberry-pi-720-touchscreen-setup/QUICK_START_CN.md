# 4.0 英寸 720×720 HDMI 触摸屏：树莓派使用说明

适用产品：本支持包对应的 4.0 英寸、720×720、HDMI 视频输入、USB 触摸屏。已实测的平台为 Raspberry Pi 4 Model B、Raspberry Pi OS Bookworm Desktop 64 位。其他树莓派型号、系统和驱动板版本需另行确认。

## 1. 准备设备和系统

准备树莓派、已安装系统的 microSD/TF 卡、树莓派电源、HDMI 连接线，以及支持数据传输的 USB 线。树莓派 4 使用 micro-HDMI 输出，请根据屏幕端的实际接口选线，勿混淆 micro-HDMI 和 mini-HDMI。

树莓派 4 建议使用合适的 5.1V/3A USB-C 电源。屏幕的供电电压、电流及接法，以本产品标签和接线图为准；不要把树莓派电源规格当成屏幕规格。

如 TF 卡已有可用系统，可直接使用。需要安装新系统时，可用 Raspberry Pi Imager 将系统写入 TF 卡。本次实测使用 Bookworm Desktop 64 位；本包暂不承诺其他系统版本兼容性。

如果准备通过电脑远程配置，请在写入系统时设置自己的用户名、密码、Wi-Fi，并启用 SSH。已安装的系统也可在桌面或 Raspberry Pi Configuration 中设置。客户使用自己创建的登录凭据；不要假设所有系统都使用 pi/raspberry。

## 2. 连接屏幕

先关闭树莓派并断电，再接线。

| 连接 | 作用 |
| --- | --- |
| 树莓派 HDMI 输出 → 屏幕 HDMI 输入 | 传输显示画面 |
| 树莓派 USB 口 → 屏幕触摸 USB 口 | 传输触摸数据；供电能力以产品接线图为准 |
| 屏幕所需电源 | 按屏幕标签和接线图连接 |
| 树莓派 USB-C 电源 | 给树莓派供电 |

USB 线必须支持数据传输。只接 HDMI，或把触摸 USB 口只接到充电器，都不能把触摸信号传给树莓派。若屏幕有多个 USB 接口，请按产品接线图选择触摸数据接口。

接好屏幕、USB 数据线和所需电源后，启动树莓派，等待桌面出现。

## 3. 显示与触摸均正常时

无需安装本包的显示兼容配置。保持屏幕原生分辨率 720×720；本次实测的正常输出约为 60Hz。触摸控制器在本次实测系统中由内置 USB HID/多点触摸驱动自动识别，未另行安装触摸驱动。

## 4. 黑屏、无信号或画面闪烁时

本次实测的驱动板在 Raspberry Pi 4 上需要专用显示时序兼容配置。仅把宽、高改成 720×720，可能仍不能显示。先检查接线和供电，再安装卖家提供的本支持包；不要直接套用其他屏幕的 config.txt 参数。

如果当前屏幕无法操作，可先用普通显示器，或者让电脑与树莓派连在同一局域网，通过 SSH 配置。主机名、用户名和 IP 取决于客户自己的设置。

在电脑上解压整个支持包文件夹。如果在另一台电脑上操作，可在电脑终端执行以下命令，把 YOUR_USER 和 YOUR_PI_IP 替换为实际用户名、树莓派 IP；先进入解压后文件夹的上一级目录：

```bash
scp -r raspberry-pi-720-touchscreen-setup YOUR_USER@YOUR_PI_IP:~/
ssh YOUR_USER@YOUR_PI_IP
```

在树莓派终端执行：

```bash
cd ~/raspberry-pi-720-touchscreen-setup
sudo bash install.sh
sudo reboot
```

安装时请保持本屏幕的 HDMI 已连接。程序会检查树莓派型号、系统版本及屏幕识别信息；若提示不匹配，请把报错发给卖家，不要强制套用。

重启后自动应用 720×720、约 60Hz 的兼容时序。该配置仅在识别到本支持包已知的驱动板时应用，不会给其他已连接屏幕强行设置同一模式。更换屏幕后请重启，使开机识别流程重新执行。

## 5. 触摸点击无反应时

先检查触摸 USB 口是否通过支持数据传输的 USB 线接到了树莓派，而非只接充电器。若已连接，换一条已知可传数据的线，再换一个树莓派 USB 口。

可在树莓派终端查看：

```bash
lsusb
```

本次实测触摸控制器显示为：

```text
1a86:e5e3 QinHeng Electronics USB2IIC_CTP_CONTROL
```

如果没有该设备或其他触摸设备，先排查线材、接口和触摸控制器的连接。不同产品批次名称可能变化，不能仅凭名称不同就判断故障。

若 USB 设备已识别但仍无法点击、坐标反向或偏移，请向卖家提供系统版本、接口照片和诊断输出。本配置包调整显示时序，不会自动处理所有触摸坐标映射问题。

## 6. 提交诊断与卸载

在支持包目录执行：

```bash
sudo bash collect-diagnostics.sh > ~/square720-diagnostics.txt 2>&1
```

向卖家提供该文件，并说明是黑屏、闪烁、触摸无反应还是坐标偏移。请同时提供树莓派型号、系统版本和接线照片。

如需卸载本包的开机配置：

```bash
sudo bash uninstall.sh
sudo reboot
```

卸载后恢复系统自动读取屏幕参数；原本需要此兼容配置的屏幕可能再次无法显示。
