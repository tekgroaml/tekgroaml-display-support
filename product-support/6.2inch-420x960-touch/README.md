# 6.2英寸 420×960 长条触摸屏

## 产品基本信息

| 字段 | 内容 |
| --- | --- |
| 客户识别名 | **6.2英寸 420×960 长条触摸屏** |
| 尺寸/类型 | 6.2英寸，长条，HDMI视频＋USB触摸 |
| 分辨率含义 | 420×960是样机EDID上报及成功输入模式；厂家原生规格待核对 |
| SKU/ASIN/厂家料号/批次 | 尚未取得，不以EDID名称替代 |

驱动上报的产品名称和物理尺寸可能未按面板定制，不作为尺寸测量依据。

## 简述问题

原始约51.85Hz下能出图，但出现闪烁/显示完整性异常。`auto`仍选回同一条原始首选时序，普通`set`也不能生成正确的新时序。

## 修复数据

| 参数 | 原始 | 验证成功值 |
| --- | --- | --- |
| 有效分辨率 | 420×960 | 420×960，保持不变 |
| 像素时钟 | 28MHz | **32.4MHz** |
| 刷新率 | 约51.851852Hz | **60Hz** |
| 同步极性、前后沿、总长 | 上表所示 | 全部保持不变 |

只修改第一详细时序的像素时钟与基础EDID校验和，保留其他字段和扩展块。触摸样机已确认画面完整稳定、闪烁消失；同尺寸非触摸样机同参仍异常，不能套用为通用修复。

## 修复脚本

正式文件名：**`6.2inch-420x960-60hz-ltm-zl480.sh`**。

正式配置ID：`6.2inch-420x960-60hz-ltm-zl480`。旧名`ltm-420x960-60`继续兼容。正式命名及同名脚本入口需要[工具仓库](https://github.com/tekgroaml/tekgroaml-pi-display-tools)的2.3.0或更新适用版本。

以接口1临时应用为例（会重启桌面，先保存文件）：

```bash
screen-config apply --port 1 --profile 6.2inch-420x960-60hz-ltm-zl480 --confirm-profile
```

或安装应用后，从代码目录运行同名脚本：

```bash
bash scripts/profiles/6.2inch-420x960-60hz-ltm-zl480.sh --port 1 --confirm-profile
```

`--confirm-profile`表示已核对产品变体，不绕过EDID匹配。先临时观察成功，再加`--save`；该命令没有自动倒计时恢复。恢复命令：

```bash
screen-config auto --port 1 --save
```
