# 6.2英寸长条触摸样机：420×960 / 60Hz兼容处理

本资料对应一次已成功验证的**6.2英寸、HDMI视频＋USB触摸样机**，提供树莓派上的闪烁排查和兼容时序设置。

**真实厂家型号尚未取得。** 系统显示的`LTM ZL480`是驱动板EDID名称，不是可靠的产品料号。420×960是这块样机验证成功的输入模式，不能据此宣布所有同尺寸面板的原生分辨率。发布到具体商品时，卖家应先核对SKU、面板/驱动板料号和批次。

工具从 [TEKGROAML Pi Display Tools](https://github.com/tekgroaml/tekgroaml-pi-display-tools) 获取，需要**2.2.0或更新且仍支持此配置档的版本**。本目录不重复打包另一套安装脚本。

配置档名称：`ltm-420x960-60`，它是软件配置名，**不是产品型号**。

## 核心限制

- 触摸样机：420×960、像素时钟32.4MHz、60Hz，用户确认画面完整稳定、闪烁消失。
- 同尺寸非触摸样机：报告相同EDID，使用同样时序后仍出现亮度明暗变化；问题尚未解决，不在本配置的成功验证范围内。
- EDID匹配不能区分这两个变体，因此配置档要求显式`--confirm-profile`。它不验证物理面板型号，也不绕过EDID检查。
- 同一EDID可能包含重复序列号。保存的“接口＋EDID身份”不能保证区分报告完全相同数据的实体屏幕；更换样机后应先清除旧配置，再验证。
- 新CLI配置档、开机恢复及冷启动需要单独验证；手工临时时序成功不等于所有安装步骤均已实机通过。
