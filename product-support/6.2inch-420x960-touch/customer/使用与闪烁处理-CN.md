# 6.2英寸长条触摸屏：树莓派使用与闪烁处理

## 适用条件

本指南用于卖家确认与已验证触摸样机相符的产品：HDMI视频＋USB触摸、在树莓派上报告420×960 / 约51.85Hz的已知驱动板。实测主机为Raspberry Pi 4 Model B，Raspberry Pi OS Bookworm Desktop 64位，labwc / Wayland。

**请先让卖家确认购买SKU和批次。** `LTM ZL480`名称、6.2英寸尺寸或EDID匹配，均不能独立证明适用。非触摸款没有通过同样修复验证，不要因为外观相似而套用。360×960 / 60Hz在本次样机测试中也未解决问题。

## 1. 接线与供电

- HDMI线：树莓派视频输出 → 屏幕视频输入。
- 支持数据传输的USB线：树莓派USB → 屏幕触摸数据口。
- 屏幕供电：按该SKU标签及接线图，不根据USB外形猜测电压。
- 树莓派保持图形桌面登录；黑屏时可从同一局域网通过SSH操作。

如果亮度一明一暗，先确认电源和线材稳定。树莓派`get_throttled`没有欠压记录，也不能证明屏幕自己的USB供电稳定。使用独立电源对照时必须符合屏幕额定规格。

## 2. 确认接口编号和版本

| 编号 | 配置/测试 | Linux接口 | 板子接口 |
| --- | --- | --- | --- |
| 1 | `--port 1` / `--screen 1` | HDMI-A-1 | HDMI0，靠近USB-C |
| 2 | `--port 2` / `--screen 2` | HDMI-A-2 | HDMI1 |

确认应用已安装2.2.0或更新的适用版本：

```bash
screen-config --version
screen-config profiles
screen-config list
screen-config modes --port 1
```

未安装或版本过旧时，从卖家软件仓库获取新版本，按照安装说明执行。旧版没有`pi-setting`管理命令时，使用新包的`sudo bash scripts/install.sh`进行首次升级。

本指南以下用接口1举例；屏幕实际在接口2时，所有`--port 1`和`--screen 1`一起改成2。

## 3. 为什么auto和set可能不能解决

原始首选时序为420×960，像素时钟28MHz，总像素540×1000，因此刷新率约51.85Hz。`auto`会再次选回这条首选时序；`set`只接受系统已有的模式，不能凭空得到正确的60Hz时序。

本配置保持有效分辨率、同步极性和前后沿不变，只把像素时钟改为32.4MHz，使刷新率为60Hz。只在主机侧覆盖，不写屏幕或触摸控制器固件。

## 4. 先临时应用

先保存图形应用文件。应用EDID兼容档需要重启桌面，所有连接的屏幕可能短暂黑屏，图形窗口会关闭。保留SSH窗口以便恢复。

确认产品适用后执行：

```bash
screen-test stop
screen-config apply --port 1 --profile 6.2inch-420x960-60hz-ltm-zl480 --confirm-profile
screen-config list
```

`--confirm-profile`表示您已经核对本指南和产品变体，不表示强制跳过匹配。程序仍检查厂商/产品标识、名称、EDID结构与已知详细时序；不匹配会拒绝操作。

预期当前输出：**420×960 / 60Hz**。命令成功只说明主机接受输出，不等于实体面板一定正常。

此命令不带`--save`，因此不会新增开机保存设置。它**没有自动倒计时恢复**；测试失败时按下方命令手动恢复，或重启清除临时覆盖。若此前已有保存项，重启可能重新应用，所以恢复时建议同时清除保存项。

## 5. 观察实体屏幕

至少检查：

1. 画面是否完整、有无裁切、错位、横纹。
2. 白色或静态桌面下亮度是否持续稳定。
3. 颜色显示与触摸输入是否正常。

```bash
screen-test white --screen 1
screen-test pattern --screen 1
screen-test touch --screen 1
screen-test tap-cycle --screen 1
screen-test stop
```

`tap-cycle`初始黑色，手指按下按白→红→黑切换；无操作就保持当前颜色。`touch`用来检查实际触点和轨迹。没有触摸数据线或映射错误时，这些设置不会自动修复USB触摸。

如果触摸到了另一块屏幕，检查HDMI与USB线配对，以及是否保留了旧USB物理路径映射。更换USB插口后可能需要重新配对；请联系卖家，不要复制其他主机的路径。

## 6. 验证稳定后再保存

仅在本机实际显示稳定、卖家确认型号适用后：

```bash
screen-config apply --port 1 --profile 6.2inch-420x960-60hz-ltm-zl480 --confirm-profile --save
```

保存会记录接口、EDID身份、配置档和已确认标记，启动时再匹配后应用。首次保存后应重新登录、重启和冷启动测试。报告完全相同EDID的其他变体仍可能匹配，**换成另一块屏幕后先清除旧保存项，不要假设程序能识别真实料号**。

## 7. 显示变差或换屏时恢复

```bash
screen-test stop
screen-config auto --port 1 --save
```

恢复驱动板原始识别参数，并删除该接口由本程序保存的设置。原始约51.85Hz可能再次闪烁，这是回到修复前状态，不代表恢复命令失败。若SSH中断，先重新连接再操作；仅重启可能重新应用已保存档。

如果继续亮度闪动，停止反复尝试不同宽度或时钟，提供购买型号、驱动板标签、当前模式、供电方式和异常视频。非触摸样机的问题仍待单独定位，不能将这个配置描述为通用修复。
