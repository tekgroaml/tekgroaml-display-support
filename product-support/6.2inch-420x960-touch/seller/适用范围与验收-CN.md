# 卖家说明：6.2英寸样机时序修正与限制

## 产品命名

真实厂家型号、面板料号和生产批次尚未取得。本文称“6.2英寸触摸样机”，配置档名为`ltm-420x960-60`。不能把EDID的`LTM ZL480`当作正式SKU，也不能直接将360×960商品标注改成420×960；需要厂商核对真实面板规格与支持输入模式。

## 已记录的试验结果

| 样机/试验 | 结果 |
| --- | --- |
| 触摸样机原始420×960、28MHz、约51.85Hz | 有画面，闪烁/完整性异常 |
| 通用工具生成360×960、自称60Hz，硬件约59.56Hz | 用户反馈仍闪烁或不完整，已撤回 |
| 360×960、28.8MHz、精确60Hz，保留原前后沿 | 用户反馈仍闪烁或不完整，已撤回 |
| **420×960、32.4MHz、精确60Hz，原前后沿** | **触摸样机用户确认完整稳定、闪烁消失** |
| 同尺寸非触摸样机，420×960、32.4MHz、60Hz | 仍亮度明暗闪动，已恢复原参数；独立供电对照尚未完成 |

这些结果支持为已确认触摸变体提供候选兼容档，不能证明所有6.2英寸屏幕都适用，也不能仅凭刷新率断定所有闪烁都是同一原因。

## 成功时序

| 参数 | 值 |
| --- | --- |
| 有效宽×高 | 420×960 |
| 像素时钟 | 32.4MHz |
| 水平前沿/同步/后沿 | 50 / 20 / 50 |
| 垂直前沿/同步/后沿 | 16 / 4 / 20 |
| 水平总长×垂直总长 | 540×1000 |
| 同步极性 | 水平正、垂直正 |
| 刷新率 | 32,400,000 ÷ 540 ÷ 1000 = 60Hz |

仅首条详细时序的像素时钟28→32.4MHz及基础EDID校验和改变，其他描述和扩展块保持不变。

## 为什么不能自动按EDID套用

两块表现不同的样机报告相同的EDID名称、厂商/产品ID，甚至序列号也重复。脚本检查EDID格式、校验和、厂商/产品、名称、第一与第二详细时序、扩展结构，只能确认数据符合这个配置，**不能确认实体屏幕是成功的触摸变体**。

因此新增档默认不自动应用，手工调用要求`--confirm-profile`，保存项同时记录`profile_confirmed: true`；缺失确认时开机恢复跳过。这个标记只是用户已核对指南，不是硬件型号认证。更换实体屏幕时必须清除旧保存项，不能依赖重复EDID自动避开另一变体。

程序可采用此前手工测试留下的、字节完全等于该兼容档结果的运行时覆盖，前提是显式确认；任意未知覆盖仍拒绝接管。其他安装工具产生的配置应先独立核对。

## 客服应如何使用

1. 收集SKU/订单中的产品型号和驱动板标签，确认触摸/非触摸版本。
2. 检查供电、HDMI、USB数据链路，先确认当前实际模式及具体闪烁形式。
3. 对符合变体和数据匹配的客户，先发临时应用与恢复命令，说明桌面会重启。
4. 客户观察完整性、亮度稳定与触摸后，成功才发保存命令。
5. 非触摸样机或仍闪烁者转为独立供电/线材/厂家时序对照，不反复套同一配置。

不让客户安装720屏配置档，不发布某台机器的USB路径、账号、IP或样机完整EDID。

## 发布验收

- 已验证：手工时序在触摸样机运行中成功；非触摸样机同参失败已明确记录。
- 新2.2脚本需验证：配置匹配与拒绝、确认参数、失败恢复、保存与开机读取；代码测试结果见工具仓库。
- 尚待实机：2.2正式CLI在两变体上的完整运行、冷启动恢复、换屏后清理、卸载回退、长时间运行和不同批次。
- 产品资料待补：额定供电、清晰接线图、厂家料号、面板原生像素及支持输入模式。确认前不能对外宣称型号已认证或所有场景已解决。
