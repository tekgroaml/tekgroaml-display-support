# 6.2英寸360×960切割非触摸屏

[English](README.md) | **简体中文**

先核对订单上的尺寸、分辨率和触摸选项。优先做下面的接线检查，不用先运行脚本。

## 碰到连接线后，突然黑屏或闪烁

- 先不要动线，等约10～15秒，看画面是否恢复。
- 还没恢复，就拔下HDMI和USB供电线，重新插紧，两端都检查一下。
- 换一根线试试，先只接一块屏幕。供电按商品要求连接。

如果每次碰线都会发生，优先换线。一直不亮时，也先从这些接线检查开始。

## 手指点击没有反应

本款不带触摸，这是正常的。如果另一块触摸屏反而控制本屏，先核对另一块屏的HDMI和USB是否接在同一台主机，再按下面的Windows方法指定触摸屏。

## Windows电脑可以先试什么？

桌面右键打开**显示设置**，选中这块屏幕，选择列表中的对应分辨率。双屏想分别显示时选**扩展这些显示器**。如果闪烁，进入**高级显示**，仅在列表支持时尝试60Hz。

[Windows详细操作](../../platforms/windows/README.zh-CN.md)。后面的树莓派命令**不能在Windows中运行**。

## 亮度一直一明一暗，或画面缺边

请发一段短视频，并说明怎么供电。这块非触摸样机调到60Hz后仍有问题，目前没有已确认的软件修复；触摸款切割补偿也未在本款确认。

## 可选：树莓派操作

<summary>展开树莓派命令（不适用于Windows）</summary>

## 画面位置不动，但亮度反复一明一暗

**可能看到的现象：**内容在原位置，但背光或整体亮度持续变化。

1. 先单屏测试，按产品额定要求供电，对照已知良好的供电线及合适的独立电源。
2. 对照HDMI线和已知正常主机。
3. 打开白色及网格，便于观察：

   ```bash
   screen-config list
   screen-test white --screen 1
   screen-test pattern --screen 1
   ```

仍异常时，提供短视频、电源信息与`screen-config list`联系支持。此样机60Hz试验**未解决**，暂没有已验证的推荐配置；不因名称相同就套用触摸款档。

## 左边缺失，或画面被裁掉

执行`screen-test pattern --screen 1`并拍清四边。触摸版曾需要可见区布局补偿，但其偏移量**尚未在本非触摸版测量确认**。先联系支持测量本样机，再决定补偿参数。

## 有触摸靶点，但手指点击没反应

这是正常现象：非触摸款没有触摸输入。改用颜色及几何测试：

```bash
screen-test cycle --screen 1 --interval 5
screen-test pattern --screen 1
```

如果另一块触摸屏反而控制本屏，按[混合双屏配对流程](../_shared/README.zh-CN.md#二触摸无响应串屏与偏移)将该触摸控制器仅绑定所属输出。

## 重新连接后测试图不见了

```bash
screen-test stop
screen-test pattern --screen 1
```

仍黑屏时先查供电、背光及连接识别，再考虑时序；若出现`Remote I/O error`，提供连接信息联系支持。

#### 驱动上报记录

本样机报告同一LTM / ZL480 EDID族：256字节、`328d5e04`、420×960、28MHz、约51.85Hz，第二详细时序为480×480、18.72MHz。相同EDID不能区分触摸与非触摸，也不能确认玻璃原生规格。目录360×960依据用户商品描述，仍需对此非触摸样机独立测量标尺。

#### 一、亮度闪动／无画面

画面位置稳定，但亮度一明一暗；420×960、32.4MHz、60Hz未解决。屏幕由树莓派USB供电，树莓派未报告欠压，但不能据此证明屏幕接口处供电稳定。独立电源及线材对照尚未完成。

本非触摸样机**没有已验证的修复配置**。不能因为EDID相同就应用6.2触摸款的专用档。按额定要求检查电源，更换已知良好的供电线及电源，单屏测试，并与已知正常主机对照。EDID/DDC失败时，先解决连接读取问题，再自动选择模式。见[通用显示检查](../_shared/README.zh-CN.md#一黑屏闪烁与edid读取错误)。

#### 二、触摸响应

不适用，本款无触摸。其他屏的触摸不应落到本屏；触摸＋非触摸混用时，曾将唯一触摸控制器仅映射回其所属输出，用户确认定位正确。只有一个触摸控制器时，不直接运行需要两个控制器的配置。无触摸硬件也能显示`screen-test pattern --screen 2`等图案。

#### 三、切割窗口

X=60、宽360的补偿只在触摸样机确认；非触摸款先独立进行标尺照片及四边验证，再决定窗口。缺少触摸层不代表固件或扫描位置完全相同。本条目不宣称显示完整或60Hz已修复。
