# 2.8英寸480×480，触摸属性待确认

[English](README.md) | **简体中文**

**产品选项补充：**2.8英寸单屏系列有触摸型号。本页保留的是此前未核对具体SKU的双屏黑屏记录，不表示该系列没有触摸款；当前非触摸双屏套装另行记录。

先核对订单上的尺寸、分辨率和触摸选项。优先做下面的接线检查，不用先运行脚本。

## 碰到连接线后，突然黑屏或闪烁

- 先不要动线，等约10～15秒，看画面是否恢复。
- 还没恢复，就拔下HDMI和USB供电线，重新插紧，两端都检查一下。
- 换一根线试试，先只接一块屏幕。供电按商品要求连接。

如果每次碰线都会发生，优先换线。一直不亮时，也先从这些接线检查开始。

## 触摸没反应，或点这块屏却响应到另一块

- 先看屏幕的**USB供电／触摸线有没有插到正在输出画面的那台电脑或树莓派上**。只插充电头，屏幕可能会亮，但触摸传不到主机。
- 用能传数据的USB线。只能充电的线可能让屏幕亮起来，却不能触摸。
- 双屏时，把每块屏幕的HDMI和USB线成组核对。先只接一块及其USB线，确认后再接另一块。

请先核对订单是否带触摸；本条目样机的触摸选项尚未确认，非触摸版不会响应手指。

## Windows电脑可以先试什么？

桌面右键打开**显示设置**，选中这块屏幕，选择列表中的对应分辨率。双屏想分别显示时选**扩展这些显示器**。如果闪烁，进入**高级显示**，仅在列表支持时尝试60Hz。

触摸仍跑到另一屏时，在Windows中搜索**校准笔和触控输入的屏幕**，打开后选**设置（Setup）**，按提示指定触摸屏。先确认USB线接对，再做这一步。

[Windows详细操作](../../platforms/windows/README.zh-CN.md)。后面的树莓派命令**不能在Windows中运行**。

## 做完还是黑屏？

请发接线照片，说明背光或电源灯是否亮、使用什么电脑。已测双屏黑屏问题尚未解决，不能保证改设置就能修好。

## HDMI和电源都接了，但屏幕一直黑

1. 先只接一块，检查额定电源、电源指示灯及背光是否发亮。
2. 屏幕断电后重新插紧HDMI，再供电；对照已知良好的线及另一台主机。
3. 查看树莓派识别结果：

   ```bash
   screen-config list
   screen-config modes --port 1
   ```

4. 仅当屏幕信息可读且存在约60Hz的480×480时，尝试：

   ```bash
   screen-config set --port 1 --mode 480x480@60
   screen-test white --screen 1
   screen-test pattern --screen 1
   ```

以上是排查步骤，**不是已确认修复**。已测一块即使输出480×480、60Hz仍黑。若未恢复，提供接线及指示灯照片、电源信息和命令结果联系支持，不套用720方屏或6.2长条档。

## 执行命令出现“Remote I/O error”

测试连接上，树莓派虽然检测到HDMI，却无法读取显示信息。重新检查屏幕供电、HDMI接触及线材。`screen-config auto`依赖该读取，无法修复物理链路；回退显示1024×768不代表面板就是这个分辨率。换线及供电检查后仍报错，请联系支持。

## 能显示，但手指点击没反应

先确认订单是触摸版，再查USB数据连接。带触摸时按[触摸检查流程](../_shared/README.zh-CN.md#二触摸无响应串屏与偏移)处理；非触摸版不会响应手指。本次样机没有已验证校准或切割偏移参数。

#### 一、黑屏／Remote I/O error

可读EDID的一块已经是标称分辨率，不能用分辨率不匹配解释两块都黑。另一块无法读取EDID，`screen-config auto`依赖此读取，不能修复DDC链路故障。后续SSH也超时，不能确认最后的纯白测试已执行。

尚无已验证修复。先只接一块，按额定要求供电，检查背光及指示灯，屏幕断电后插紧HDMI，逐项对照HDMI线、USB数据线、供电及已知正常主机，再检查：

```bash
screen-config list
screen-config modes --port 1
```

仅当链路可读且模式包含约60Hz的480×480时执行：

```bash
screen-config set --port 1 --mode 480x480@60
screen-test white --screen 1
screen-test pattern --screen 1
```

这些是诊断步骤，不是已验证的黑屏修复；不套用720方屏或6.2长条档。主机没有欠压标记不代表面板端供电充足。

#### 二、触摸

尚未确认这两块是否带触摸。先核对SKU及USB输入设备，不默认归为触摸或非触摸；确认后按[通用触摸指南](../_shared/README.zh-CN.md#二触摸无响应串屏与偏移)处理，并按已核对属性重命名目录。无专属校准参数。

#### 三、切割补偿

未对本款方屏测量或验证，不使用6.2英寸窗口及触摸偏移。
