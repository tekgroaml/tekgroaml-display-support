## 一、黑屏／Remote I/O error

可读EDID的一块已经是标称分辨率，不能用分辨率不匹配解释两块都黑。另一块无法读取EDID，`screen-config auto`依赖此读取，不能修复DDC链路故障。后续SSH也超时，不能确认最后的纯白测试已执行。

尚无已验证修复。先只接一块，按额定要求供电，检查背光及指示灯，屏幕断电后插紧HDMI，逐项对照HDMI线、USB数据线、供电及已知正常主机，再检查：

```bash
screen-config list
screen-config modes --port 1
```

仅当链路可读且模式包含约60Hz的480×480时执行：

```bash
screen-config set --port 1 --mode 480x480@60
screen-test white --screen 1
screen-test pattern --screen 1
```

这些是诊断步骤，不是已验证的黑屏修复；不套用720方屏或6.2长条档。主机没有欠压标记不代表面板端供电充足。

## 二、触摸

尚未确认这两块是否带触摸。先核对SKU及USB输入设备，不默认归为触摸或非触摸；确认后按[通用触摸指南](../_shared/README.zh-CN.md#二触摸无响应串屏与偏移)处理，并按已核对属性重命名目录。无专属校准参数。

## 三、切割补偿

未对本款方屏测量或验证，不使用6.2英寸窗口及触摸偏移。
