# 2.1英寸480×480单屏触摸款

[English](README.md) | **简体中文**

卖家已确认2.1英寸单屏系列有触摸型号。请核对订单的触摸选项和分辨率，卖家已确认分辨率为480×480，专属触摸验收仍待完成；规格确认不代表测试已通过。本款与非触摸双屏套装分开说明。

## 碰线后黑屏或闪烁

先不动线，等约10～15秒。没恢复就重新插紧HDMI和USB供电线，两端都检查；反复发生优先换线，供电按商品要求。

## 点击没反应

USB供电／触摸**数据线**要接到正在输出HDMI画面的同一台电脑或树莓派。只插充电头、使用纯充电线，都不能把触摸传给主机。

## 点击却控制了另一块屏

先只接本屏及其HDMI、USB线测试。Windows仍串屏时按[Windows触摸设置](../../platforms/windows/README.zh-CN.md)操作。这些是通用检查，不代表本型号已经完成触摸验收。

## 可选：树莓派检查

先安装[显示工具](https://github.com/tekgroaml/tekgroaml-pi-display-tools)并登录图形桌面。命令不适用于Windows，接接口2时替换数字：

```bash
screen-config list
screen-config modes --port 1
```
