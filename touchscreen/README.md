## 实测与适用边界

- 本次完整验证的触摸映射修复环境：Raspberry Pi 4 Model B，Raspberry Pi OS Bookworm Desktop 64位，labwc 0.8.1，wlroots 0.18.2。
- 同时连接两块同名USB触摸控制器时，已确认两块实体屏幕各自在本屏响应、位置正常。
- HDMI视频显示还验证过480×480、720×720和800×800场景；不等于这些屏幕所有组合、多指同时操作、所有系统均已验证。
- Windows部分为系统/显示器厂商公开说明支持的排查路径，不是本产品已完成全部Windows兼容性验收的声明。
- 断电冷启动、睡眠唤醒、USB反复热拔插、多指并发和其他树莓派/系统版本，需要单独质检。
- 现有`pi-setting`工具固定提供两个接口，`--screen 1`对应HDMI0，`--screen 2`对应HDMI1；三块以上屏幕不在当前程序验证范围。

## 既有资料

720×720专项配置包已收纳到[产品支持资料](../product-support/README.md)。该配置包用于已知720×720显示时序，**不是通用触摸修复工具**。

结构化程序及其命令文档位于[TEKGROAML Pi Display Tools](https://github.com/tekgroaml/tekgroaml-pi-display-tools)。新客户应取得完整支持包，并按自己的平台和设备情况安装，不能把本机测试使用的设备编号或USB路径直接套给其他客户。
